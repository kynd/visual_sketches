<div class="prose">

Visual Sketches is a collection of small interactive studies in real-time graphics. Each page takes one question — how to draw something, how fast it can go, what it costs — and answers it with demos that run in the browser.

The first study is [Particle rendering](./particle-rendering): how many small lit spheres a GPU can draw per frame, and what changes once they cast shadows. [Noise flow](./noise-flow) sets those shadowed spheres moving through 3D noise fields, read four different ways. [Environment maps](./environment-maps) lights the plume from colour spheres and procedural skies.
